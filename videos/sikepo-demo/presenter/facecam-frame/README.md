# SIKEPO rounded facecam

Use obs-rounded-facecam.html as a local Browser Source in OBS, with source dimensions 1344 × 784. It plays the three presenter blocks in sequence. Scale the source down for the presentation corner.

The HTML applies small rounded corners, a thin off-white border, and a subtle shadow. The original MP4 files stay rectangular; the frame is applied at composition time.

Alternative: rounded-mask.png and rounded-border.png are provided for an editor that supports an image mask and overlay.
